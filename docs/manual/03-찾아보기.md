# 3. 찾아보기

## 명령
| 명령 | 하는 일 | API 비용 |
|---|---|---|
| `chimera check --target T` | 설정·대상·키·예상 비용 확인 | 없음 |
| `chimera run --target T` | 탐색 실행 | 있음 |
| `chimera regress --target T` | 회귀 세트(VERIFIED 실패)만 재실행 | 있음 |
| `chimera stop RUN_ID` | 중단 요청 | 없음 |
| `chimera resume RUN_ID` | 이어서 실행 | 있음 |
| `chimera status [RUN_ID]` | 실행 목록·상태 | 없음 |
| `chimera report RUN_ID` | 리포트 다시 만들기 | 없음 |

모든 명령은 `--config 파일` (기본 `config.toml`)을 받는다. 실행은 `python -m chimera ...`.

## 설정 (`config.toml`)
| 위치 | 항목 |
|---|---|
| `[limits]` | `max_cost_usd_per_run`(1회 상한) · `max_cost_usd_per_day`(하루 상한) · `max_tests_per_run` · `max_model_calls_per_run` · `max_wall_minutes` · `max_consecutive_errors` |
| `[loop]` | `probe_limit` 계열당 탐색 수 · `families_per_invariant` · `repro_n` 재현 횟수 · `deepen_limit` · `stale_streak` 새 정보 없는 연속 턴 · `exploit_share_max` 집중 탐색 비율 상한(테스트 상한 대비) · 재시도 설정 |
| `[models.<키>]` | `provider` · `model_id` · 단가(USD/100만 토큰) · `cache_read_usd_per_mtok` · `max_tokens`(생각 토큰 포함) · `effort` · `timeout_s` · `price_source` |
| `[roles]` | `attacker`(WEDGE) · `judge`(채점기) — 모델 등록표의 키 |
| `[allowed]` | `targets` 실행을 허용한 대상 |

## 대상 명세 (`targets/<id>.toml`)
- `prompt_file` 대상 프롬프트 · `model` 대상 모델 키
- `[[oracles]]` 판정 기준: `type` = `RUBRIC_BASED`(LLM 채점기) / `DETERMINISTIC`(코드 검사만). `checks` = `forbid_regex` / `require_regex` / `max_chars`. `acceptance`·`rejection` 조건 (id 필수, 명세 전체에서 유일)
- `[[invariants]]` 불변조건: `oracle`, `source`(USER_CONFIRMED / SPECIFICATION_DERIVED / ENGINE_INFERRED), `attack_families`

## 상태값 (서로 다른 축)
| 축 | 값 | 누가 |
|---|---|---|
| 실행 상태 (시도) | NOT_EXECUTED · EXECUTED · ERROR · CANCELLED · BLOCKED | EXECUTOR |
| 평가 결과 (테스트) | PASS · FAIL · INVALID · INCONCLUSIVE · NOT_RUN | VERIFIER |
| 검증 상태 (실패) | PENDING · VERIFIED · DISPUTED · REJECTED | CODEX |
| 워크플로 단계 | ACQUIRE · PROBE · FOCUS · DEEPEN · SPLIT · VERIFY · NEXT_INVARIANT | 코드(controller) |
| 실행(run) | CREATED · RUNNING · STOPPING · STOPPED · BLOCKED + 멈춘 이유 | 코드 |

- **NEXT_INVARIANT** = 원본 WEDGE의 RESEED (이름만 바뀜).
- **PASS/FAIL** = 대상 프롬프트가 그 테스트에서 규칙을 지켰는가. 공격 성공 = 대상 FAIL.
- **VERIFIED** = 같은 입력 3회 재실행 중 같은 조건 FAIL이 1회 이상. VERIFIED만 회귀 세트에 들어간다.
