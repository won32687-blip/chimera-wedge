# 1. 설치와 첫 실행 (Windows PowerShell)

모든 명령은 **PowerShell**에서, 저장소 폴더(`chimera-wedge`) 안에서 실행한다.

## 1-1. 준비물 (한 번만)
1. Python 3.11 이상: https://www.python.org/downloads/ 에서 설치. 설치 화면에서 **"Add python.exe to PATH"에 체크**.
2. Git: https://git-scm.com/download/win
3. 확인:
   ```powershell
   python --version
   git --version
   ```

## 1-2. 내려받기와 설치 (한 번만)
```powershell
cd $HOME
git clone https://github.com/won32687-blip/chimera-wedge.git
cd chimera-wedge
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
```
> 이후 모든 명령은 `.\.venv\Scripts\python`으로 실행한다. (가상환경 "활성화"를 하지 않아도 되도록 이렇게 쓴다.)

## 1-3. Mock으로 전체 흐름 확인 (API 호출 없음, 비용 0원)
```powershell
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\python -m chimera run --target mock_demo --config config.mock.toml
```
정상이면 마지막에 이렇게 나온다:
```
실행 run_xxxxxxxxxxxx 종료: STOPPED / NO_TARGETS_LEFT
```
리포트 파일 위치도 함께 출력된다 (`data\mock\runs\<run_id>\report.md`). 리포트에서 **재현 확인(VERIFIED) 2개**가 보이면 루프가 계획→실행→판정→검증→기록→다음 결정까지 끝까지 돈 것이다. (Mock 대상에는 결함 2개를 일부러 심어 두었다.)

## 1-4. API 키 설정
키는 파일에 쓰지 않고 환경 변수로만 쓴다.

지금 열린 PowerShell 창에서만 쓰기:
```powershell
$env:ANTHROPIC_API_KEY = "여기에-키-붙여넣기"
```
계속 쓰기 (새 PowerShell 창부터 적용):
```powershell
setx ANTHROPIC_API_KEY "여기에-키-붙여넣기"
```

## 1-5. 실제 대상 준비
1. `targets\devils_advocate_prompt.md`에 Strategic Devil's Advocate 프롬프트 원문을 붙여 넣고 저장 (UTF-8).
2. `targets\devils_advocate.toml`의 불변조건·판정 조건을 확인한다 (지금은 초안).

## 1-6. 실행 전 확인 (API 호출 없음)
```powershell
.\.venv\Scripts\python -m chimera check --target devils_advocate
```
역할별 모델, 호출 1회 최대 예약액, 1턴 예상 상한, 키 설정 여부, 오늘 사용액이 나온다.

## 1-7. 실제 실행
```powershell
.\.venv\Scripts\python -m chimera run --target devils_advocate
```
- 1회 $1, 하루 $3를 넘을 호출은 **시작 전에 차단**된다.
- 멈추기: `Ctrl+C` 한 번(진행 중 호출 1건만 끝내고 멈춤), 두 번(즉시). 자세한 내용은 [런북](02-런북.md).
